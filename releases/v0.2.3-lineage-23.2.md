# v0.2.3 — JIT、应用兼容与原生媒体解码更新

LineageOS 23.2 / Android 16 BP4A 的 LoongArch64 Waydroid 测试版。附件是
2026-09-19 已在设备部署并完成回归验证的同一组 system/vendor 镜像，未重新
更换构建内容。源码对应 [v0.2.3](https://github.com/factfinding/lineage-waydroid-loongarch64/tree/v0.2.3)。

## 本版变化

- 汇总近期 ARM64 Lite JIT 加载性能优化，以及指令回退进度、线程/进程和应用兼容修复。
- ARM64 RenderScript 补充库进入完整镜像，不再需要额外的库覆盖文件。
- 修复媒体 YUV/RGB 输出协商、颜色缓冲区、GPU YUV 导入及 AAC 空间相位边界问题。
- 固化 Instagram 使用系统原生解码器的兼容策略；应用版本变化仍可能影响该策略。
- 保留经过验证的图形设备信息兼容设置。本次包含 Google 服务框架和 Play 商店；
  已安装的个人应用、账号及用户数据不在镜像中。
- [Helper 坐标映射修复](https://github.com/factfinding/waydroid-helper/commit/8e2c6fcf6dfab43b0769817f48f15170e9dfd248)
  同步发布在宿主项目中，Helper 本身不包含在 Android 镜像里。

## 环境与安装

使用 LoongArch64 AOSC OS、Wayland 桌面和支持 binder/binderfs 的 **4 KiB 页面内核**。
检查 `getconf PAGESIZE` 应为 `4096`。虽然含有部分大页兼容修复，本版 ARM64 应用
运行验证基于 4 KiB 内核，不应将其视为完整的 16 KiB 兼容保证。

宿主包仍使用 [Waydroid 1.6.3-2](https://github.com/factfinding/waydroid/releases/tag/loongarch64-1.6.3-rel2)
和[启用 seccomp 的 LXC 7.0.0-1](https://github.com/factfinding/aosc-os-abbs/releases/tag/lxc-7.0.0-1-loongarch64)。
已安装匹配版本时无需重复安装。至少预留 8 GiB 磁盘空间，以及用户数据备份所需空间。

下载本 Release 的全部附件，在下载目录校验并解压：

```bash
sha256sum -c SHA256SUMS
zstd -d system.img.zst -o system.img
zstd -d vendor.img.zst -o vendor.img
sha256sum -c SHA256SUMS-images
```

升级前关闭按键映射窗口，并备份重要 Android 数据。现有安装先停止会话和容器：

```bash
waydroid session stop
sudo systemctl stop waydroid-container
sudo lxc-info -P /var/lib/waydroid/lxc -n waydroid -sH
mountpoint /var/lib/waydroid/rootfs
```

确认 LXC 显示 `STOPPED` 且 rootfs **未挂载**后，再备份旧镜像、配置和覆盖层：

```bash
release_backup="/var/lib/waydroid/deploy-backups/$(date +%Y%m%d-%H%M%S)-v0.2.3"
sudo mkdir -p "$release_backup"
sudo cp -a /etc/waydroid-extra/images "$release_backup/images"
for config in waydroid.cfg waydroid_base.prop waydroid.prop; do
    if sudo test -f "/var/lib/waydroid/$config"; then
        sudo cp -a "/var/lib/waydroid/$config" "$release_backup/"
    fi
done
for directory in overlay_rw overlay_work; do
    if sudo test -d "/var/lib/waydroid/$directory"; then
        sudo mv "/var/lib/waydroid/$directory" "$release_backup/"
    fi
done
sudo mkdir -p /var/lib/waydroid/overlay_rw/{system,vendor} \
    /var/lib/waydroid/overlay_work/{system,vendor}
```

旧覆盖层会完整保留在备份中，防止旧库或属性遮住新镜像；自行添加过的其他系统
定制也会暂时移入备份，需要逐项核对后恢复。不要将旧覆盖层整体重新盖到新镜像上。

首次安装可跳过上述旧安装备份步骤。安装本版两张配套镜像：

```bash
sudo install -d -m 0755 /etc/waydroid-extra/images
sudo install -o root -g root -m 0644 system.img vendor.img /etc/waydroid-extra/images/
```

首次安装再执行 `sudo waydroid init -i /etc/waydroid-extra/images`。
现有安装的 `waydroid.cfg` 应已指向该镜像目录，无需为升级清空数据或重新初始化。
启动服务，然后以桌面用户打开窗口：

```bash
sudo systemctl enable --now waydroid-container
waydroid show-full-ui
```

首次启动需要等待。另开终端检查：

```bash
sudo waydroid shell getprop sys.boot_completed
sudo waydroid shell getprop ro.build.version.incremental
sudo waydroid shell getprop ro.vendor.build.version.incremental
```

预期分别为 `1`、`1789785338`、`1789785338`。不要删除 `/var/lib/waydroid/data`。
回滚时先停止会话和容器，确认卸载完成，保存当前镜像和覆盖层，再从对应备份恢复
旧 system/vendor、overlay_rw/overlay_work；配置仅在需要时恢复。

## 验证与已知限制

- 实机保留用户数据升级成功，桌面正常，运行组件哈希匹配镜像，无额外覆盖文件。
- Berberis **211/211**，原生颜色/GPU YUV/AAC 测试 **8/8** 全部通过。
- H.264 字节缓冲区及 Surface、VP9 Surface、原生 dav1d AV1 Surface 均输出 **60/60** 帧并到达 EOS。
- YUV 与 RGBA 并行输出颜色正确；不支持的 RGB565/P010 请求被明确拒绝。
- AAC 选择和 Instagram 进程内兼容策略探针通过，验证结束时 Android 崩溃缓冲区为空。
- ARM64 转译仍为实验功能，部分游戏、保护运行时和应用可能缓慢、卡住或拒绝运行。
- 测试主机此前出现过整机自动重启，根因尚未定位；本版不宣称修复该问题。
- Surface 视频测试验证帧交付与时间戳，颜色和 GPU 导入另有测试；本次没有重新进行
  游戏对局、加载计时或 Instagram 在线播放对比。硬件视频解码路径未完成运行验证。

## English

This experimental release publishes the exact September 19 device-validated
LineageOS 23.2 / Android 16 image pair. It includes accumulated Lite JIT and app
compatibility work, packaged ARM64 RenderScript, per-instance YUV/RGB media
negotiation, GPU YUV import and AAC fixes, and the Instagram native-decoder policy.
Google services and Play Store are included; personal apps, accounts and user data
are not. The separately published Helper update runs on the host.

Use a **4 KiB-page** LoongArch64 AOSC kernel with binder/binderfs, Wayland, and the
linked Waydroid/LXC packages. Download all assets, run both checksum checks, and
follow the commands above. For upgrades, stop the session/container, confirm LXC
is stopped and rootfs unmounted, and back up both images, configuration and entire
overlay directories. Install the matched pair with fresh overlays and retain
Android user data. Only a first installation needs `waydroid init`. The expected
system/vendor incremental version is `1789785338` and boot-completed is `1`.

Validation passed 211 Berberis and eight native color/GPU/AAC tests; H.264, VP9 and
native AV1 controls delivered all 60 frames. Translation and application support
remain experimental. Previous whole-host automatic resets on the test machine
remain unexplained; this release does not claim to resolve them. No new gameplay
or online Instagram comparison was performed. To roll back, stop/unmount again,
preserve the new files and restore the matching old images and overlay pair.

The source tag, source index and patch queues identify the corresponding code.
The attached build manifest is a post-patch inventory rather than a directly
syncable upstream manifest. LLVM/Rust/WebView bootstrap recipes are included in
the source repository; a fresh clean bootstrap was not repeated for this release.
